# 铁饭碗模拟器

一款文字类仕途模拟游戏。2026 年，你 22 岁，考公上岸，从青阳县市场监管局的一名科员开始，
每一年做一次选择，直到退休、或者走不动为止。

## 部署

**Vercel**（推荐）：在 Vercel 导入本仓库，Framework Preset 选 `Other`，
Build Command 和 Install Command 都留空，Output Directory 填 `.`，直接 Deploy 即可。
仓库内的 `vercel.json` 已配好路由与缓存策略（HTML 不缓存，改动即时生效）。

**GitHub Pages**：仓库 Settings → Pages → Source 选 `main` 分支根目录即可。

**本地**：下载 `index.html` 双击打开就能玩，不需要任何服务器。

## 玩法

每年一个回合，流程为：

```
随机事件 → 做出选择 → 分配剩余精力 → 年终结算 → 干部任免
```

- **六项指标**：政绩、人脉、身体、家庭、存款，以及一项风险值
- **精力分配**：每年 8–12 点精力，投向工作 / 关系 / 家庭 / 健康 / 学习，单项上限 5 点
- **晋升机制**：任职年限 + 是否有空出坑位 + 政绩人脉评分 × 年龄系数
- **年龄红线**：每一级都有参考年龄线，过线后评分开始打折，越拖越难
- **时代浪潮**：每 6–9 年抽一张时代牌（机构改革、政务大模型、延迟退休、极端气候……），改写规则与事件池

## 职级序列

```
科员 → 副科 → 正科 → 副处 → 正处 → 副厅 → 正厅 → 副部 → 正部 → 副国级 → 正国级
```

退休年龄随职级递增：正处及以下 65 岁，副厅 68 岁，副部 70 岁；
到达副国级后进入「加时赛」，何时退休由你自己决定。
